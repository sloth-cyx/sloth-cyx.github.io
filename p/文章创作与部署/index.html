文章创作与部署

使用Hugo & Stack来创造博客文章！

2026-05-20

Hugo

整个过程请参考文末教程链接。

创建Hugo文件夹

a. 在github下载hugo压缩包。
 Github Hugo
b. 解压后，在hugo.exe的位置/文件夹开启cmd。
c. 使用以下命令来创建hugo文件夹。
 hugo new site <文件夹名字>
 hugo new site hugoStackBlog
d. 把hugo.exe复制到创建好的文件夹，例如示例的hugoStackBlog。

使用Stack主题

a. 在github下载stack压缩包。
 Hugo主题 Stack
b. 如何应用请参考文末教程链接。

创建新文章

a. 使用以下命令来创建新的文章。
 hugo new content <文件夹>/<文件夹>/<文件名称.md>
 hugo new content post/information/mdWritting.md
b. 使用以下命令来生成public文件夹并启动本地服务，既在localhost:1313里查看效果；public文件夹是被部署到github上的文件夹。
 hugo server -D

Git

初次部署

a. 在github官网创建仓库（repositories），取名为用户名.github.io，例如sloth-cyx.giythub.io。
b. 把hugo.yaml的baseurl改成你创建好的仓库名（https://sloth-cyx.github.io），然后照着github的指示开始把public文件夹部署到github上。
* 需在public文件夹内呼出cmd！
* git add README.md需换成下面的命令行来直接把全部public文件夹一次性加入到上传行列。
 git add .
c. Github上的操作请参考文末教程链接。

发布新文章

在public文件夹内使用以下git命令行来让新文章部署到github上。

1
2
3

    git add .
    git commit -m "更新说明"
    git push

Git命令行

a. 检查哪些文件有变更
 git status
b. 添加全部变更文件
 git add .
c. 添加指定文件
 git add 文件名.后缀
d. 保存更新纪录
 git commit -m "更新说明"
e. 第一次连接 Github 仓库
 git remote add origin https://github.com/Git名字/仓库名.git
f. 初次上传Github（-u记住这个远端branch，往后就不需要)
 git push -u origin main或master
g. 后续上传Github
 git push
h. 下载远端更新
 git pull
i. 查看本地分支
 git branch
j. 查看全部分支
 git branch -a
k. 切换分支
 git switch 分支名
 git checkout 分支名
l. 创建并切换分支
 git switch -c 分支名
m. 删除本地分支
 git branch -d 分支名
n. 强制删除本地分支
 git branch -D 分支名
o. 删除远端分支
 git push origin --delete 分支名
p. 查看远端仓库
 git remote -v
