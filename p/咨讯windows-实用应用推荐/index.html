【咨讯】Windows 实用应用推荐

~推荐日常实用的免费Windows应用~

2026-10-13
2026-10-14

SubtitleEdit

  • 用来开MP3+vtt的文件，比如dlsite，也可以用于调整字幕的应用（毕竟本身是个字母编辑器）。
  • 官方网址：https://www.nikse.dk/subtitleedit
  • 选择File → Open → .vtt文件即可，同名mp3会自动加载。

Locale Emulator

  • 有些中文exe开启时会呈现乱码，这是很典型的Windows非Unicode程序编码不匹配。
  • 有时会看到正常中文+乱码，那部分可能使用Unicode字体/文本组件；标题和按钮却可能是ANSI字符串，所以出现「一部分正常、一部分乱码」。
  • 此应用可以让exe以简体中文运行，不影响其他路软件。
  • 官方网址：https://github.com/xupefei/Locale-Emulator
  • 安装后，右键exe → 显示更多选项 → Locale Emulator → Modify Application Profile
  • 然后右键exe → 显示更多选项 → Locale Emulator → Run with Application Profile

Bulk Rename Utility

  • 解决文件批量命名的难题，例如统一已下载番剧的名字。
  • 官方网址：https://www.bulkrenameutility.co.uk/

Baregrep

  • 文件内容搜索工具，可以快速搜索多个文件中的指定文字或关键词，不过无法搜索中文。
  • 官方网址：https://www.baremetalsoft.com/baregrep/
  • 示例图：

Everything

  • Windows 文件搜索工具，通过文件名快速定位电脑中的文件和文件夹，搜索速度极快。
  • 右键搜索到的文件 → Open Path → 快速打开文件所在文件夹
  • 官方网址：https://www.voidtools.com/support/everything/
  • 示例图：

WinMerge

  • 文件与文件夹比较工具，可以找出两个文件或文件夹之间的差异，并支持合并修改。
  • Ctrl+N 快速打开新的对比板块，可以拖拽文件至左右对比。
  • 官方网址：https://winmerge.org/?lang=en
  • 示例图：

SpaceSniffer

  • 硬盘空间分析工具，以可视化方块图展示文件和文件夹的占用空间，方便找出占空间的大文件。
  • 官方网址：https://space-sniffer.com/
  • 示例图：

Geek Uninstaller

  • 软件卸载工具，可以卸载程序并扫描清理残留文件、文件夹和注册表项目（registry）。
  • 官方网址：https://geekuninstaller.com/
  • 示例图：

AnyDesk

  • 远程桌面控制工具，可以通过网络连接并操作其他电脑，适合远程协助、技术支持及文件传输。
  • TeamViewer的替代品，稳定性和速度与其媲美。
  • 官方网址：https://anydesk.com/en

Proton VPN

  • 免费VPN：不限流量，适合日常浏览&长期连接。
  • 节点涵盖日本、美国、新加坡等地区，但不能自由选国家；系统自动分配，更换节点有冷却时间。
  • 故缺点为不能指定想要的国家节点。
  • 官方网址：https://protonvpn.com/
