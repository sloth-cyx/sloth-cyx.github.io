  5. 另外，泷奈一定要注意1技能别点太高。其原因在搭配百暴时，米兰达的暴击buff提供给全爆裂时间后的最高攻成员；而泷奈太高攻的话，会抢走米兰达大招的攻击力和暴伤buff，得不偿失。如果1技能点4都抢buff的话，就需要重置到1了（苦笑）。
  6. 综上所述，泷奈是张典型的功能卡，属于需要用的时候很香，不需要的时候纯仓管。故优先级给到T3，具体看玩家需求培养。

XP打分

[!VIOLET]

  • 7/10
  • 原皮茨瓦伊其实有点问题，上本身非常好，保守的校服下包裹着隐藏的大胸（最喜欢这种若隐若现有想象空间的衣服啦2333），但下半身…全副装甲看起来和上半部分不太搭配。
  • 所幸月pass的常服茨瓦伊救回来不少，就是很有学生的青春气息，靓丽可爱，有点邻家小妹风。

要点：

  1. 茨瓦伊属于高暴击+穿透拐，她的技能提供了18.63% +（15% × 3）= 63.63%暴击率，配合妮姬自带的15%的暴击率，总计可达78.63%的暴击率。
  2. 在敏特实装之前，茨瓦伊只能搭配原皮白雪登场。由于原皮白雪自带26.1%的暴击率，两者组合能够稳定达成百暴，成为新一代的铁甲百暴队。
  3. 敏特实装后，其自带的19.94%的暴击率搭配茨瓦伊正好非常接近百暴，只需要主C携带任何一阶的暴击词条就可达成百暴条件。敏特也带给了茨瓦伊本身没有的攻击力和暴伤乘区，所以两人的相性非常好。
  4. 当然这个组合也有限制，敏特的暴击率仅覆盖双数回合，所以茨瓦伊+敏特只有在双数回合可以达成百暴。由于这个特殊性，带两个C是亏的（因为另一个C在单数回合亏伤害），反而是四保一最好（一个大C和一个辅C可以最大化利好这种配置）。
  5. 于是，在进行S37个突水优过激派时，重装白雪成为了第二个契合茨瓦依的主C。
  6. 茨瓦伊相对米兰达的好处在于对于重装白雪这种快照百暴C来说，茨瓦依的百暴是覆盖全爆裂10秒的，不像米兰达只能提供一发百暴。但也有缺点，茨瓦伊这种穿透拐总会有伤害占比问题，不如米兰达提供的攻击力和暴伤拐能覆盖全部伤害类型。
    例如重装白雪的穿透伤害占比仅约15%，而米兰达提供的攻击力加成却能作用于100%的伤害，因此在多数环境下依然具备竞争力。
  7. 那为什么S37的水冷个突中茨瓦伊会比米兰达更合适？其原因就在过激派存在核心+多判，这大幅放大了穿透收益，同时让茨瓦伊全爆裂期间的百暴优势得到完整发挥。若换成单判环境，两者优劣则未必如此明显。
  8. 而且，我个人认为茨瓦伊在铁甲个突也未必搭配原皮白雪，而是机制上更加契合的小红帽（因为小红帽的穿透占伤害占比100%，每一下平A都是穿透），而原皮白雪继续搭配米兰达，这就能出两队百爆了。当然，问题也就出在小红帽数值跟不上了，对于四保一的那个一，小红帽是有心无力的，以及有没有过激派这种环境的个突（核心，多判），这套思路仍有待验证。
  9. 综上所述，茨瓦伊现阶段仅在 铁甲 和 水冷 就业。对于已经拥有米兰达的个突玩家来说，茨瓦伊的提升幅度不高，故优先级不高排在T3；个突前排玩家（1%以上）适当提高优先级和练度。

XP打分

[!VIOLET]

  • 10/10
  • 看似保守， 但若隐若现的内衬透出来的效果超级大加分；不色却更色。这让本来不喜欢巨乳的我也能接受，巨乳细腰阿嘶…赛高！
  • 无敌的性格，开朗主动，对爷主打一个喜欢，结婚！虽然背负的东西很沉重，但却更加让人怜爱，也因此才显得她的这个性格多么的宝贵和高洁。

要点：

  1. 阿尔卡娜是一张极其特殊的卡，她的横空出世不仅提拔了伊莎贝尔，使其从1红一跃成为3红以上的输出角色，让阿尔卡娜获得了伊莎贝尔的人形珍藏品之称；更是让灰姑娘成为了牢不可破的电击最大C，成为了 电击 最大刀不可忽视的存在。
  2. 一项一项来说，阿尔卡娜的机制注定绑定需要减全爆裂时间的电击C，而伊莎贝尔成为了不二人选。暴力的180%基准加攻和180%的攻伤加成把伊莎贝尔一下子就提到了电击前3C的级别（由于伊莎贝尔是旧时代的产物，意味着没有什么自拐能力，吃拐率反而得以提高）。而伊莎贝尔自身的暴击率加成和易伤能力也恰好和阿尔卡娜的拐力错开，两人搭配相得益彰，成为了卷电击个突必须要练的卡。
  3. 接下来解析一下灰姑娘，灰姑娘的伤害大头源于开启爆裂技能时的技能伤害，而这部分属于快照伤害，意味着灰姑娘的大招吃不到全爆裂开始时的buff（例如超阿的攻击力和攻伤都在全爆裂开始时才提供）。
    快照意思为一旦启动了第一下伤害，这一下伤害的buff会被定格记录，因此后续的追加伤害buff量也不会变动；不会发生例如前4下伤害没buff，而后6下伤害有buff的这种情况，这也是灰姑娘的一个痛点。
  4. 而阿尔卡娜+伊莎贝尔这个组合却能缩短全爆裂时间，这导致了灰姑娘的大招能吃到全爆裂开始时的buff！
    例子 - 超阿+阿尔卡娜+伊莎贝尔+灰姑娘+皇冠：伊莎贝尔开第一波大，全爆裂结束时超阿的buff还有5秒，如果充能够快（3-4秒能完成），那么灰姑娘的大招是可以吃到上一轮超阿的残余buff，甚至阿尔卡娜还有提供不少全爆裂结束后的buff，这些buff大大的提高了灰姑娘的大招收益！
  5. 甚至充能再快点甚至还能吃到伊莎贝尔的易伤buff…来自参考视频的评论区：由于伊莎贝尔的大招是分三段触发的，第三段触发易伤时，实际全爆裂时间已经过了1-2秒了；全爆裂结束时，伊莎贝拉易伤仍然存在2.5秒。
    参考视频：【NIKKE】灰姑娘配队杂谈——从快照机制说起。
  6. 而且阿尔卡娜的减CD和伊莎贝尔的减全爆裂时间也能把原本三分钟内正常循环的13-14次爆裂提高到18次左右，灰姑娘本来只开6-7次爆裂一下次提高到了9次！还记得说过灰姑娘的伤害大头来源于大招伤害么？这是极其恐怖的加成。
  7. 在S36的电击个突中，超阿+阿尔卡娜+伊莎贝尔+灰姑娘+皇冠的最大刀甚至和第二刀差了快一倍（参考电天王Kira的记录）。
  8. 综上所述，阿尔卡娜在电击个突的优先级非常之高， 属于追求电击个突的玩家（1%以上）必须养的T1卡！追求排名可以继续往上养成。

[!ERROR]

  • 7/10
  • 小小的身体里蕴含着巨大的能量，这句话形容贝斯蒂再适合不过；小只害羞却有着罗刹火力的一面把反差感拉满。

要点：

  1. 战贝是张强力PVP卡的同时也是一张特殊的PVE卡，这都是由于她本身的机制都围绕着真伤的缘故。
  2. 没错，在泷奈篇也提过，真伤在PVE的定位不是普遍的个突出高分，而是在于越战推图。这方面，战贝是毫无疑问的T0级别选手，她的全屏大招和超大范围AOE真伤普攻毫无疑问的让她成为越战的唯一真神。但，还是要再一次说明等级越高，战贝在推图的优先级就越往下降。
  3. 但不同于泷奈的是，战贝的推图强势可以带到企业塔里（毕竟没有反常塔），超毗+女仆双子+战贝+海伦也是现在的主流极乐塔阵容。
  4. 这里也要补充一点，越战推图多数情况指的是小怪关而非boss关。Boss关和个突一样的，真伤吃瘪，也意味着战贝在这个突这方面并不突出。除非是定制高防御并且是 燃烧 优越的boss，如席兹才有出场机会。
  5. PVP方面，战贝则是超级C，竞技场的防御力在战贝面前不值一提，让她输出高的同时充能也不俗。不屈王阿姨，一拳超人，肉贝斯蒂等各种套路相对出现，也证明了她的兼容性极高。缺点就是精养的养成压力极高，但成型后非常恐怖，4攻8暴的12词条贝斯蒂简直就是当之无愧的“杀神”。
    当然，这里也要声明不代表12词条的战贝就无敌了，PVP正是因为各种阵容互相克制才会如此有魅力，战贝也有被克制的时候！
  6. 综上所述，在前中期玩家手里，战贝的优先级还是不错的，属于PVP和PVE都有一席之地的角色。对后期玩家来说，战贝的PVE价值会更低，仅仅是把她定位成PVP卡的存在。至于后期玩家养不养则取决于其是不是专精PVP并且是冠军竞技场选手；若不是，现在的特殊竞技场其实3个队伍C已经溢出了，战贝属于锦上添花但绝不是必须的存在，可以酌情选择不培养。

[!TIP]

  • 9/10
  • 性感的小恶魔，谁又能不败倒在她石榴裙下呢？
  • 中式的女仆装设计很好的给薇尔维特的姣好身段大方的展现出来，巨乳细腰美臀的葫芦形身材已经是二次元的天花板了。尤其右边眼角的痣简直了，加分！

要点：

  1. 薇尔维特（以下简称VV）本质上来说，是小美人鱼的人形珍藏品，联盟战里更是被称为 风压 马斯特。
  2. 先说VV的机制，VV的弹药袋是算在子弹消耗的，轴内VV相当于5.9个机枪，轴外相当于3.6个机枪。这机制非常契合小美人鱼消耗子弹的机制以达成追加伤害和充能的效果！
  3. 轴外VV为何可以取代马斯特在联盟战风压的地位？其原因之一自然是拐小美人鱼，另一个原因是在她100.8%的蓄力攻击伤害，非常适配现在的风压大刀（小美人鱼+VV+娜由塔+水母+黑莲）。
  4. 虽然蓄力攻击伤害普遍上并不被看好，但VV给的数值之高引起了质变；以水母为例，她自身的250%蓄力伤害加上100.8%足足有40%的提升，虽然要考虑普攻在全部伤害占比的问题，但无疑也是不错的拐量了。
    在这个最大刀里，主C娜由塔黑莲水母都能吃到这个蓄力伤害加成！虽然黑莲的伤害大头在技能伤害，但娜由塔和水母的普攻伤害占比不错，加上VV拐的小美人鱼部分，总伤已经超过娜马（但这个配队仅适合联盟战，个突需要5个队伍，能不能组成这个队伍还是个问号，有待考证）。
  5. 轴内VV是个副C，虽然能极大的增强小美人鱼伤害的同时自己也能打出不俗的输出，但作为代价失去了攻击力&蓄力伤害的拐力。VV的两种定位无疑增加了VV+小美人鱼的灵活性（甚至硫磺火老师还开发出了百暴美人鱼的打法）。
  6. 综上所述，VV在风压场合是个非常好用的辅助卡，联盟战不仅可以解放马斯特，个突里和小美人鱼的搭配也非常灵活不吃环境（点名某方舟**游侠），故在T2的基础上升半档，优先级为T1.5。

要点：

  1. 目前 风压 第一大C，集伤害，充能，蓄速拐于一身的女人。
  2. 莉贝雷利奥（以下简称水母）所有的机制都围绕一个机制，蓄速。水母的蓄速拐（1.5秒 × 0.1274 = 0.19秒）只给攻击力最低的基本爆裂3队友包括自己，所以只能组11233或12233的阵容。
  3. 这里稍微解释一下，基本爆裂3为图标上是爆裂3的妮姬，所以小红帽不算，而超毗作为1号位使用的时候也会抢走水母的蓄速buff，导致另一个3号位吃不到，比如黑莲。3号位的拐更是要极力避免，比如初音【珍藏品】也会抢走本应属于黑莲的buff。这些毒点导致水母其实有不少配队限制。
  4. 重点说一下皇冠，皇冠由于给开大的队友加攻，会导致皇冠+黑莲+水母的配队黑莲第一个开大的话，如果黑莲和水母的练度差距不大，大概第一次爆裂黑莲是吃不到水母的蓄速buff的。参考下述的流程，记住皇冠buff15秒，充能够快会有上轮残余buff：
    黑莲开大（皇冠+黑莲>水母=吃不到蓄速）>水母开大（水母+皇冠>黑莲+皇冠=黑莲吃蓄速）>黑莲开大（水母+皇冠>黑莲+皇冠=黑莲吃蓄速）>水母开大（水母+皇冠>黑莲+皇冠=黑莲吃蓄速）…以此循环，所以最好水母先开大。
  5. 接下来说说水母自己的蓄速提升，虽然水母技能不吃任何蓄速改动包括debuff，但词条是吃的，也不影响她的基准蓄速拐，具体流程：
    基准蓄速拐结算（吃面板） -> Loading页面加载词条 -> 进游戏水母技能发动（免疫蓄速变动）
  6. 具体说说蓄速词条的水母的提升。首先，水母每一下普通攻击是有追加伤害的，水母全爆裂开始时的160%攻击力提升是3秒，水母的基础蓄力时间是1.5秒；就算水母掐着点进入全爆裂时直接在0.1秒射，但剩下的2.9秒依旧无法让水母完成2下总计3秒的普攻。
  7. 第一个质变点，6-8%的蓄速增加（1.5秒 × 0.06 = 0.09，四舍五入0.1秒）让水母得以达到1.4秒的蓄速；一样情况水母掐着点进入全爆裂时直接在0.1秒射，但这次剩下的2.9秒可以让水母完成2下总计2.8秒的普攻，尤其水母的追加伤害不是快照，所以追加伤害吃得到160%攻击力对伤害的提升有着不小的作用（但水母似乎还是需要3-4条蓄速词条才能确保第3个普攻的追加伤害吃满160%攻击力buff）。这也让水母全爆裂结束的最后一下普攻追加伤害能更加稳定的吃到全爆裂的buff。具体算法可参考 妮游小课堂：大百科 - 装弹&蓄速词条 这篇文章。
  8. 第二个质变点，17%的蓄速增加（1.5秒 × 0.17 = 0.255，四舍五入0.26秒）让水母从全爆裂10秒的6-7发普攻增加至8-9发，这可是有33%的提升（当然实测数据有没有理论这么漂亮就不好说了，没看到有类似数据结果）。但是，为了达到这17%的蓄速追上限，这无疑牺牲了水母的配队灵活性，导致她必须待在换弹速度非常高的队伍如皇初，女仆双子等。
  9. 相对的，追下限虽然只让水母从原本的全爆裂6-7发普攻增加至7-8发，但装弹无疑让水母的配置更加灵活的同时也不那么依赖换弹队。
  10. 由于追加伤害的存在，水母在PVE和PVP的充能都是非常顶的。蓄速拐+充能高的特点也让她得以在跨属的个突中使用，其中最为经典的便是跨属分摊队，还有 水冷 个突的布蕾德， 电击 个突的超尼（尤其超尼也是一个极其依赖蓄速追上限的角色）。
  11. 综上所述，水母是个PVE和PVP都有上场空间的角色，甚至PVE还有诸多功能性以及跨属性带来的实用性让她一跃登顶成为 风压 最强角色没有之一，T1优先级实至名归。但想要追上限的话，养成压力极其大，甚至还会增加配队难度。这里仅推荐风压个突前排玩家追11-12词条，普通个突玩家4攻4优1+装弹已经很好了。
